# Record a plan deviation

Read
[`../../../.claude/skills/deviate/SKILL.md`](../../../.claude/skills/deviate/SKILL.md)
completely before taking task actions, then follow it as the canonical operating
procedure.

Never record an approved deviation until the user explicitly approves that
specific departure. Use `--origin llm` for an agent proposal and leave it
proposed until the user confirms it.
