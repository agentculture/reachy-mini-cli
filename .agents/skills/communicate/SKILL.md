# Communicate across repositories and the Culture mesh

Read
[`../../../.claude/skills/communicate/SKILL.md`](../../../.claude/skills/communicate/SKILL.md)
completely before taking task actions, then follow it as the canonical operating
procedure.

Reuse the canonical scripts under
`../../../.claude/skills/communicate/scripts/`. Choose exactly one appropriate
channel for an ask: a tracked GitHub issue or comment when an audit trail is
needed, or a Culture mesh message for ephemeral coordination. Never duplicate
the same ask across both.
